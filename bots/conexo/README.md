# Conexo Discord Bot

Discord bot for playing [Conexo](https://conexo.ws) (Connections-style daily grouping game).

## Game Mechanics
- Players are presented with 16 words in a 4x4 grid.
- Objective: Find 4 groups of 4 related items without making 4 mistakes.
- Group difficulties: Easy, Medium, Hard, Tricky.

## Planned Features
- Daily puzzle synchronization from conexo.ws
- Interactive Discord UI components (Buttons / Select Menus) for selecting groups of 4
- Mistake counters (lives / strikes)
- Per-channel cooperative or competitive play
- Shareable spoiler-free results card
